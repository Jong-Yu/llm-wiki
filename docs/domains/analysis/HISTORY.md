- 변환 저장·부분 확정·계획 생성의 입력을 업무 TypedDict로 명시하고, 라우터4곳에서 검증된 HTTP 모델을 profile 없는 dict로 전달한다. 업무 진입점3곳은 `body=` 호환과 기본값·nullable·검증/인가/저장 순서를 유지하며 중첩 자료를 복사해 입력과 반환값을 분리한다.

## 2026-11-25 — 직접 입력의 고정 등록과 변환 진단 분리
