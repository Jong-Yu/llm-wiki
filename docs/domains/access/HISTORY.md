## 2026-11-19 — 요청한 신규 계정의 SDV 플랫폼 배정

- 후속 명시 요청으로 같은 계정의 SDV 플랫폼 권한을 현재 지원하는 전체 업무 권한9종(`read`, `source_write`, `write`, `ontology_write`, `ontology_review`, `ontology_policy`, `conversation_write`, `result_write`, `comparison_write`)으로 확대했습니다. 공통 인증 잠금·미완료 가입 부재·revision 대조·원자 게시·재읽기 검증을 수행했고 대상 permissions 외 모든 정책 필드가 동일함을 확인했습니다. 서버 관리자 권한을 새로 만들거나 다른 공간 권한을 부여하지 않았습니다.

- 사용자 요청으로 이름이 일치하는 단일 미배정 계정을 기존 `sdv-platform`에 배정하고 기본 공간으로 지정했습니다. 별도 쓰기 권한 요청은 없어 `read`와 중립 `default` 프로필만 부여했습니다.
- 기존 `.auth.lock`으로 가입과 직렬화하고 미완료 가입 기록 부재·정책 revision·정책 유효성을 확인한 뒤 기존 원자 게시 함수를 사용했습니다. 저장 후 전체 정책을 다시 읽어 대상 소속·기본 공간만 변경됐고 다른 계정·인증 필드는 보존됐음을 확인했습니다. 토큰 재발급·서버 재시작·위키 자료 변경은 하지 않았습니다. 실제 사용자 앱의 배정 재확인은 남아 있습니다.
