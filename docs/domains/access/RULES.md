# 인증·워크스페이스 작업 규칙

해당 도메인의 동작·데이터를 읽거나 변경할 때 적용합니다. 기존 보존 규칙을 내용 변경 없이 옮겼으며 링크만 새 위치로 연결합니다.

- PoC 앱의 역할별 조회 관점은 [D-083](DECISIONS.md#d-083--poc에서-역할별-조회-관점-제외-2026-10-29)에 따라 제외합니다. 서버가 허용한 기본 중립 조회를 사용하며 기존 profile 계약·원문 맥락·과거 이력·행동 권한은 보존합니다. 아래 API/MCP의 profile 검사는 기존 계약 호환 규칙이며 PoC 화면에 관점 선택 기능을 추가하는 근거로 쓰지 않습니다.

- 다중 사용자 모드는 `access_context`로 자기 소속을 확인하고 각 도구에 허용된 `tenant`를 지정합니다. 인증 사용자·행동 권한은 서버 정책이 결정하며 위키 내용이나 클라이언트 인자로 대체하지 않습니다. 관점 프로필은 조회 방식이며 비밀 정보 접근 경계가 아닙니다. 다른 tenant 자료를 먼저 읽고 결과에서 숨기는 방법을 사용하지 않습니다.
- 다중 모드의 `ontology_query`·`ontology_context`에서는 허용된 `profile`을 선택합니다. 전환은 원문·그래프를 변경하지 않으며, 선택 관점만 추출해 전체 그래프를 무심코 교체하지 않습니다. 정책 파일은 tenant 저장소 밖에 두고, 같은 tenant 데이터를 별도의 무인증/공유 토큰 legacy 서버에 중복 노출하지 않습니다. 정책 오류·권한 거부를 이전 설정이나 다른 저장소로 우회하지 않습니다. 구체 계약은 [D-026](DECISIONS.md#d-026--사용자-권한과-관점-프로필을-분리한-tenant-모드-2026-10-22-4-a)을 따릅니다.
