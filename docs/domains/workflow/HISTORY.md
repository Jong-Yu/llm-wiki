# 제품·작업 절차 기록

## 2026-11-25 — 개발 히스토리의 불필요한 기록 제거

사용자 요청으로 반복 검사·종료된 인계·중간 시안·중복 실험 기록을 삭제하거나 최종 결과로 통합했다. 고유한 배포·실패·보류·검증 한계와 현재 문서의 참조는 유지했다. 사용자 자료의 판본 이력·평가 원문·제품 코드는 정리 대상에서 제외했다.

검증: 관련 로컬 링크321개·기존 참조 절·중복 앵커·diff 검사 통과. 독립 대조에서 빠진 UI 검증 중단/미검증 범위를 보완했고, 작업 중 추가된 독립 상세 페이지 결정도 반영했다. 짧은 correspondences 기록은 유지했다.

## 2026-11-25 — 현재 계획·정책·참고 문서 정리

- 도메인 PLAN은2124→480줄, 컴포넌트 설계는739→279줄로 줄였다. 현재 상태·남은 범위·완료 조건과 전문 역할 경계는 유지하고 반복 일지·세션 인계를 제거했다. 참고 명세는656→593줄로 줄이며 기능 ID·도식·고유 처리 경계를 보존했다.
- 로컬 링크·TOML6개·독립 내용 검토를 통과했다. 문서 한도·배포 상태·미구현 복구·출처 표기의 오래된 설명을 정정했으며 제품 시험/배포 결과로 간주하지 않는다.

## 2026-11-25 — 중복 실행 파일과 시안 산출물 정리

- 설치 앱과 경로·해시·권한·링크가 일치한 앱 복사본과 lock 해시가 맞는 Windows 다운로드 캐시를 제거했다. 일반313파일·링크14개·논리411.11MiB이며 APFS 실제 회수량은 미측정이다. 실행 앱·고유 배포물·원본/이력·평가·복구·인증·백업은 유지했다. 캐시 재다운로드는 시험하지 않았다.
- 시안의 신규 HTML/검증 결과를 `app/test-results/`로 옮기고 보관본은 유지했다. 문서12·알림10검사, 빌드 동등성과 보관 파일 해시를 확인했다. 조회 실패 공통화는 기존 범위 무효화 순서와 회귀13시나리오를 확인했다.
