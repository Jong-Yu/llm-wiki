### 2026-11-08 — 전체 지도의 속성 상세 선택 복구

개념 상세에서 속성 행을 눌러도 반응하지 않던 연결을 복구했습니다. 같은 패널에서 속성 값·단위·원문을 읽고 개념 정보로 돌아가며, 선택한 개념과 판본을 기준으로 기존 상세 조회를 검증합니다. 클릭·키보드·원문 왕복·개념 제거 과업과 제품 검사를 통과한 수정본을 설치했습니다. Mac 재잠금으로 설치본의 마지막 직접 클릭은 확인하지 못했습니다. [검증·설치 기록](../../../app/test-results/ontology-attribute-detail-20261108/verification.md)을 따릅니다.

### 2026-11-08 — 지금까지의 지도 개선 설치 반영

### 2026-11-07 — 사용자 과업으로 재검토한 지도 조작 시안

사전 설명 없는 별도 검토에서 여러 문서의 개념 추가·제거, 상세를 읽으며 보기 변경, 관계 이동과 원문 왕복을 수행했습니다. 반복 검색 열기·숨은 제거·상세가 가리는 도구·복귀 경로 단절을 확인하고 상단 개념 띠, 연속 추가, 직접 제거/되돌리기, 상세 위 도구, 이전 개념/원문 복귀를 연결했습니다. 검색은 항상 전체 문서를 대상으로 하며 문서 선택은 개념 목록 탐색으로 구분합니다. 실제 과업 전후·30시험·제품 빌드·1280/320px 결과는 [검토 보고서](../../../app/test-results/ontology-journey-proposal-20261107/review.md)를 따릅니다. 위2026-11-08 사용자 승인·설치 기록에 따라 반영했습니다.

후속 요청으로 개념 추가 결과에는 이름·출처·추가 여부만 남기고 연결 미리보기를 제거했습니다. 문서 행은 개념 목록을 열고 개념 행만 추가합니다. 중복 개념 버튼·집계 문구를 덜어낸 과정과 최종 선택 패널 캡처·추가 동작 검증은 같은 보고서의 [개념 추가 후속 보완](../../../app/test-results/ontology-journey-proposal-20261107/review.md#개념-추가-후속-보완)을 따릅니다.

제품 빌드와 격리 UI/HTTP 회귀 및 실제 화면 검증의 결과는 [이번 HISTORY](HISTORY.md#2026-10-31--확정-ui-규칙의-제품-반영)를 따릅니다. 문서 읽기·온톨로지·채팅의 작업 영역899/900/901 및1199/1200/1201 전환,320px 재배치, 밝음/어두움, 선택 hover·수동 탭·초안/초점 보존을 확인했습니다. 전체 WCAG 적합성이나 실제 AI 실행까지 완료했다는 뜻은 아닙니다.

후속 접근성 검수에서 공통 화면·주요 작업/오류 상태의 WCAG 자동 검사, 사용자 글자 간격·200% 페이지 확대, 실제 키보드 조작과 접근성 트리를 확인했습니다. 대비·이름·오류 연결·초점 복귀와 확대된 검토함의 행동 접근 문제를 수정했습니다. 세부 범위와 자동 판정의 수동 확인 근거는 [접근성 검수 기록](HISTORY.md#2026-10-31--접근성-검수와-실제-결함-보완)을 따릅니다.

남은 제품 적용은 위의 화면별 배치 누락과 대표 업무 자료를 사용한 레퍼런스 대조입니다. 남은 환경 검증은 VoiceOver/NVDA 실제 음성 발표와 보조기술 전체 흐름, 실기기 터치/Windows입니다. 글자 전용 확대는 별도 실행하지 않았으며 WCAG1.4.4에 허용되는 페이지 확대로200%를 검증했습니다. 실제 AI 호출과 패키지·설치 앱 갱신은 이번 실행에 포함하지 않았습니다. 같은 기준으로 후속 결함을 확인하며, 새 기능·업무 계약 변경은 별도 범위로 다룹니다.

### 2026-10-31 — Base UI 문제 도출

사용자가 Select를 하나의 예로 들며 요청한 범위를 공통 기반 요소의 진단으로 한정했습니다. [Base UI 감사](USABILITY_AUDIT.md#2026-10-31--가장-기본적인-base-ui-문제-도출)에 치수·내부 여백·크기 변형·정렬·문자·폼 구성·선택·포커스·비활성·오류·페이지 여백·안내의 12개 문제를 실측/코드 근거로 구분했습니다. 제품 코드는 변경하지 않았습니다.

후속 적용의 기준은 같은 역할·크기의 실제 치수와 상태 표현 일치, 작은 크기 등 명시적 변형의 보존, 행/속성 정렬 및 좁은 폭에서의 일관성입니다. 화면별 업무 구조 판단과 Base UI 구현 완료를 구분하며, 오류·비활성 hover·체크박스·일부 반응형의 실제 상태 검증은 남아 있습니다.

### 2026-10-31 — 사용자 피드백에 따른 세부 작업 재설계 판단

### 2026-10-31 — 실제 제품 화면을 참고한 패널과 정보 구조 정리

### 2026-10-29 — 문서 간 관계 화면 임시 숨김

- 전체 제품 빌드와 격리 HTTP/Electron·React 검증을 통과했습니다. 실제 시나리오·초기 실패와 수정·미실행 범위는 [HISTORY](HISTORY.md#2026-10-29--ia-화면-이동과-업무-모달-적용)를 따릅니다. 주소·보관 경계 결정은 [D-082](DECISIONS.md#d-082--대상-주소와-초안을-유지하는-화면-이동-및-업무-모달-제거-2026-10-29)에 기록했습니다.

### 2026-10-29 — 실제 제품 화면을 재사용한 세션 전후 비교

- 기존 단순화 시안은 실제 화면과 비교하기 어렵다는 피드백에 따라 교체했습니다. 실행 중인 Electron의 공통 프레임과 AI 채팅을 확인하고 실제 AppShell·KnowledgeChat·스타일·토큰을 재사용했습니다. 같은 화면 인스턴스에서 `현재 화면`과 `변경안`을 전환합니다.
- 변경안에는 기존 헤더의 실행 표시·계정 잔여량과 별도 세션 목록만 추가합니다. 기존 경로·테마·대화·입력 배치를 유지하며, 병행 확정된 문서 간 관계 메뉴 숨김과 D-083 조회 관점 제외는 양쪽에 동일 적용했습니다. 모의 대화·사용량은 시안 데이터로 표시합니다.
- 1024px 비교 영역에서 전후 사이드바·채팅·입력창의 위치와 크기가 동일하고 초안·선택 대화·테마가 유지되는 것을 확인했습니다. 밝음/어두움, 헤더→목록→대화 이동과 브라우저 오류 없음도 확인했습니다.
- 이번 비교 범위는 헤더·세션 목록·기존 채팅입니다. 채팅 외 상세 화면은 연결 대상과 미연결 범위를 안내하며 새로 그리지 않았습니다. 작업 도중 공유 UI 소스가 변경되어 확인한 성공 빌드를 고정 보존했습니다. 최신 제품의 자동 반영이나 실제 다중 실행·한도 조회 구현은 아닙니다.
- 이후 기존 화면 변경 시안도 [앱 규칙](../../../app/AGENTS.md)에 따라 실제 컴포넌트와 동일 자료·크기의 전후 비교로 작성합니다.

### 2026-10-29 — 동시 AI 세션·헤더 상태등 시안

- 사용자가 여러 AI 세션을 동시에 사용하는 구조와 디자인 시안 우선을 선택했습니다. 세션별 대화·초안·실행/저장/완료/미확인/중단 상태를 목록에서 확인하고 다른 세션을 선택해도 실행과 입력을 유지하는 방향입니다.
- 헤더 사용량 영역 왼쪽에 작은 녹색 점멸 표시와 `AI 세션 ›` 텍스트 버튼을 함께 배치해 목록으로 이동하는 동작을 드러냅니다. 현재 실행이 없으면 점멸을 멈추며, 접근성 이름과 움직임 줄이기를 지원합니다. 버튼 전체를 눌러 세션 목록을 열고 개별 결과·확인·중단·재개 행동은 세션에 연결합니다.
- 세션 목록과 AI 채팅은 별도 화면입니다. 목록은 여러 화면에서 시작한 작업의 종류·대상·실행 상태·이동할 화면을 표시합니다. 항목을 누르면 목록을 벗어나 해당 대화 또는 추출·산출물·검토 화면을 열고, 각 화면에서 목록으로 돌아옵니다. 이동은 실행을 다시 시작하지 않으며 대상 확인이 불가능하면 기록을 유지하고 안내합니다. 실제 구현에서는 표시명과 별도로 대상 식별자를 보관하고 접근 시 현재 권한·존재 여부를 확인합니다.
- 사용자가 헤더 사용량 표시를 선택해 해당 안으로 시안을 정리했습니다. 계정 전체 한도를 막대로 표시하고 상세 정보는 설정에서 확인합니다. 숫자는 시안 예시 또는 명시한 미확인 상태이고 실제 계정 조회가 아닙니다. 완료 OS 알림은 미결정으로 유지합니다.
- 시안에서 두 실행 세션과 완료/저장 확인/미확인/중단 상태, 개별 초안·신규 생성·중단/재개·전체 종료를 연결했습니다. 최초 두 배치안의 72조합 및 상호작용 검증은 [검증 기록](HISTORY.md#2026-10-29--동시-ai-세션-목록과-헤더-상태등-시안)을 따릅니다.
- 이 시안 단계에서는 제품의 동시 실행 제한·CLI 서비스·서버 계약을 변경하지 않았습니다. 후속 다중 실행 제품 연결은 위 최신 절을 따르며 충돌→AI 수정 상세 시안은 별도 범위입니다.

구조 결정은 [D-070](DECISIONS.md#d-070--현재-화면을-기본-ui로-통합-2026-10-28), 실제 검증과 미실행 범위는 [이번 기록](HISTORY.md)을 따릅니다. 아래 기존 제품 구현·검증은 당시 범위이며 현재 노출 화면과 새 검증 결과를 대신하지 않습니다.

## 기존 제품 구현 상태

개인 실행 환경에 Codex·Claude Code 선택과 각각의 실행 경로를 추가했습니다. 현재 제공자와 다음 시작 선택을 구분하고 저장·재시작으로 적용하며 기존 v1 설정은 Codex로 유지합니다. 분석·질문·추출안 모두 선택한 CLI를 사용합니다. 제공자별 로그인 진단, POSIX 기본 Claude 설치 경로 탐지, 설정 보존·실제 Electron 재시작·두 제공자의 질문/추출안 연결 검증과 제품 빌드를 완료했습니다. 합성 모델 fixture 검증과 실제 Claude 모델 호출을 구분하며 HISTORY (정리로 삭제된 참고 자료)에 결과를 기록합니다.

2026-10-26 UI 구성 1~10의 공개 모듈과 구성11의 실행 환경·패키징을 실제 앱에 통합했습니다. 문서의 지식·검토·질문 진입, 저장 질문의 개인 AI 실행·답변 보관, 불변 결과→편집 초안→비교·명시 Wiki 반영, 전체 추출안 검증·적용, 원본 변환→분석 계획→기존 작업 확인·실행/재개를 연결했습니다. 문서·원본 판본·변환 보고 참조와 선택 tenant/profile을 공개 feature 입력으로 전달합니다. 실제 사용 API는 앱 연결표 (정리로 삭제된 참고 자료)를 따릅니다.

문서와 개인 기록 본문의 읽기 폭은 최대960px이며, 지도는 명시한 배율을 유지합니다. 1920×1080의 프레임·패널 치수를 유지하고 1280×720 및 낮은 창에서는 실제 작업 영역 너비에 따라 패널을 전환합니다. 문서 탭·긴 제목과 대화·비교 열을 내용 영역에 맞추며, 저장 답변의 재조회가 작성 중인 다음 질문과 그 CAS 기준을 초기화하지 않습니다. 최신 치수·캡처와 남은 상세 확인은 레이아웃 검토 (정리로 삭제된 참고 자료)에 있습니다.

main의 공통 연결 인스턴스에 업무별 HTTP/개인 CLI 서비스를 연결했습니다. OS 보호 저장 복원은 IPC/창을 열기 전에 현재 사용자·권한·관점을 재확인하며, 명시 연결 해제는 저장된 자격증명도 삭제합니다. renderer에는 제한된 요청·검증된 응답을 공개합니다. 원본 파일·토큰은 main에서 처리하고 위키1MiB·원본/첨부20MiB, CAS·응답 유실·부분 저장·정리 경고를 구별합니다. 저장 성공은 실제 서버 영수증으로 확인합니다.

MD/TXT/PDF/XLSX/DOCX와 일반 이미지13개 확장자의 원본을 보관합니다. 개인 PC의 변환 보고·원문 위치·미독 범위·저장 영수증을 표시하고 저장된 완전한 보고만 질문/계획에 명시 전달합니다. 생성 중 답변과 서버 저장 답변, 클라이언트 진단과 사람 승인을 구별합니다. 계획 인계·화면 조회는 AI를 자동 실행하지 않습니다.

개인 실행 환경 화면은 Python 프로젝트·실행 파일, Codex, Tesseract·언어 데이터의 네이티브 선택·설치/업데이트 안내·실제 진단·다음 시작 적용 설정을 제공합니다. Windows 실행기 보완을 반영한 macOS arm64 미서명 DMG·ZIP, Windows x64 미서명 NSIS 설치 파일과 개인 Python 소스 ZIP을 이전 v0.1.0 후보2 차수에 만들었습니다. 교차 빌드에도 Mac Electron을 복사하던 공통 electronDist 고정을 제거해 대상 OS·CPU의 공식 바이너리를 사용합니다. 이전 Mac 배포 앱에서 저장한 격리 설정을 새 앱으로 열어 최소 PATH 진단·설정 보존·재시작을 확인했고, DMG/ZIP/NSIS 무결성과 실제 포함된 앱·Python 소스 일치를 확인했습니다. 후보2를 포함한 이전 배포 파일·원시 검증 산출물은 삭제했으며 현재 남은 배포본은 위 최신 차수입니다. 최신 정리 검증 (정리로 삭제된 참고 자료)을 따릅니다. 서명·공증·실제 Windows 설치·공개 배포는 수행하지 않았습니다. 명령·수동 업데이트·Windows 설치 후 진단은 [앱 실행 안내](../../../app/README.md)를 따릅니다.

후보2는 검증된 앱3개 배포물을 같은 SHA256으로 재사용하고 최종 의미 검사 지침의 Python 실행기만 새로 묶었습니다. 규약 조립에 필요한 `.agent/ontology_semantics.md` 한 파일의 누락도 보완했습니다. 추출한 ZIP만 사용하는 격리 작업 폴더에서 실행기9모듈 import·규약7컴포넌트 조립·CLI6종 도움말을 확인했고, 전체245소스/requirements/리소스의 현재 파일 일치를 [실행기 검증](../../../app/release/v0.1.0-candidate2-20261026/verification/runtime-isolation-check.json)에 남겼습니다.

추출안 화면에서 고정 입력의 실제 개인 AI 실행·취소·후보 비교·정확한 후보/작업/결과에 연결된 별도 검사 보고를 조회합니다. 미저장 초안·미확인 요청·변환·추출안은 OS 보호 저장 후 같은 현재 인증 범위에서 복원하며 자동 AI/POST 재실행과 오래된 CAS 교체는 하지 않습니다. 종료·계정 전환은 암호문을 보존하고, 인증된 명시 로그아웃은 현재 서버/사용자 자료를 삭제하며 늦은 쓰기를 차단합니다.

변환 화면의 초기 복구·수동 조회가 끝나기 전에 첫 실행 클릭을 무시하던 경쟁은 ui_9 담당자가 수정했습니다. 새 공통 빌드의 실제 Electron 전체27검사가 통과했습니다. 질문 인용 v2의 고정 참조, 의미 보고의 유효 부분 보존, OCR 회전·배치 경고는 기존 UI 응답 계약으로 연결하며 새 UI 스키마를 만들지 않았습니다.
