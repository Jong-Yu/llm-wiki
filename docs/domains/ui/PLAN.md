# Electron UI 계획

## 현재 상태

개인 실행 환경에 Codex·Claude Code 선택과 각각의 실행 경로를 추가했습니다. 현재 제공자와 다음 시작 선택을 구분하고 저장·재시작으로 적용하며 기존 v1 설정은 Codex로 유지합니다. 분석·질문·추출안 모두 선택한 CLI를 사용합니다. 제공자별 로그인 진단, POSIX 기본 Claude 설치 경로 탐지, 설정 보존·실제 Electron 재시작·두 제공자의 질문/추출안 연결 검증과 제품 빌드를 완료했습니다. 합성 모델 fixture 검증과 실제 Claude 모델 호출을 구분하며 [HISTORY](HISTORY.md)에 결과를 기록합니다.

2026-10-26 UI 구성 1~10의 공개 모듈과 구성11의 실행 환경·패키징을 실제 앱에 통합했습니다. 문서의 지식·검토·질문 진입, 저장 질문의 개인 AI 실행·답변 보관, 불변 결과→편집 초안→비교·명시 Wiki 반영, 전체 추출안 검증·적용, 원본 변환→분석 계획→기존 작업 확인·실행/재개를 연결했습니다. 문서·원본 판본·변환 보고 참조와 선택 tenant/profile을 공개 feature 입력으로 전달합니다. 실제 사용 API는 [앱 연결표](../../../app/docs/api-coverage.md)를 따릅니다.

문서와 개인 기록 본문의 읽기 폭은 최대960px이며, 지도는 명시한 배율을 유지합니다. 1920×1080의 프레임·패널 치수를 유지하고 1280×720 및 낮은 창에서는 실제 작업 영역 너비에 따라 패널을 전환합니다. 문서 탭·긴 제목과 대화·비교 열을 내용 영역에 맞추며, 저장 답변의 재조회가 작성 중인 다음 질문과 그 CAS 기준을 초기화하지 않습니다. 최신 치수·캡처와 남은 상세 확인은 [레이아웃 검토](../../../app/docs/responsive-layout-audit.md#구성-7-공통-통합-후속-2026-10-25)에 있습니다.

main의 공통 연결 인스턴스에 업무별 HTTP/개인 CLI 서비스를 연결했습니다. OS 보호 저장 복원은 IPC/창을 열기 전에 현재 사용자·권한·관점을 재확인하며, 명시 연결 해제는 저장된 자격증명도 삭제합니다. renderer에는 제한된 요청·검증된 응답을 공개합니다. 원본 파일·토큰은 main에서 처리하고 위키1MiB·원본/첨부20MiB, CAS·응답 유실·부분 저장·정리 경고를 구별합니다. 저장 성공은 실제 서버 영수증으로 확인합니다.

MD/TXT/PDF/XLSX/DOCX와 일반 이미지13개 확장자의 원본을 보관합니다. 개인 PC의 변환 보고·원문 위치·미독 범위·저장 영수증을 표시하고 저장된 완전한 보고만 질문/계획에 명시 전달합니다. 생성 중 답변과 서버 저장 답변, 클라이언트 진단과 사람 승인을 구별합니다. 계획 인계·화면 조회는 AI를 자동 실행하지 않습니다.

개인 실행 환경 화면은 Python 프로젝트·실행 파일, Codex, Tesseract·언어 데이터의 네이티브 선택·설치/업데이트 안내·실제 진단·다음 시작 적용 설정을 제공합니다. Windows 실행기 보완을 반영한 macOS arm64 미서명 DMG·ZIP, Windows x64 미서명 NSIS 설치 파일과 개인 Python 소스 ZIP을 [v0.1.0 후보2 차수](../../../app/release/v0.1.0-candidate2-20261026/)에 만들었습니다. 교차 빌드에도 Mac Electron을 복사하던 공통 electronDist 고정을 제거해 대상 OS·CPU의 공식 바이너리를 사용합니다. 이전 Mac 배포 앱에서 저장한 격리 설정을 새 앱으로 열어 최소 PATH 진단·설정 보존·재시작을 확인했고, DMG/ZIP/NSIS 무결성과 실제 포함된 앱·Python 소스 일치를 확인했습니다. 현재는 후보2 설치 파일을 유지하며 이전 설치 파일·해제본을 정리했습니다. 모든 검증 기록·실패 증거와 소형 Python 소스 ZIP은 보존하며 [용량 정리 검증](HISTORY.md#2026-10-26--오래된-설치-파일과-해제본-정리)을 따릅니다. 서명·공증·실제 Windows 설치·공개 배포는 수행하지 않았습니다. 명령·수동 업데이트·Windows 설치 후 진단은 [앱 실행 안내](../../../app/README.md)를 따릅니다.

후보2는 검증된 앱3개 배포물을 같은 SHA256으로 재사용하고 최종 의미 검사 지침의 Python 실행기만 새로 묶었습니다. 규약 조립에 필요한 `.agent/ontology_semantics.md` 한 파일의 누락도 보완했습니다. 추출한 ZIP만 사용하는 격리 작업 폴더에서 실행기9모듈 import·규약7컴포넌트 조립·CLI6종 도움말을 확인했고, 전체245소스/requirements/리소스의 현재 파일 일치를 [실행기 검증](../../../app/release/v0.1.0-candidate2-20261026/verification/runtime-isolation-check.json)에 남겼습니다.

추출안 화면에서 고정 입력의 실제 개인 AI 실행·취소·후보 비교·정확한 후보/작업/결과에 연결된 별도 검사 보고를 조회합니다. 미저장 초안·미확인 요청·변환·추출안은 OS 보호 저장 후 같은 현재 인증 범위에서 복원하며 자동 AI/POST 재실행과 오래된 CAS 교체는 하지 않습니다. 종료·계정 전환은 암호문을 보존하고, 인증된 명시 로그아웃은 현재 서버/사용자 자료를 삭제하며 늦은 쓰기를 차단합니다.

변환 화면의 초기 복구·수동 조회가 끝나기 전에 첫 실행 클릭을 무시하던 경쟁은 ui_9 담당자가 수정했습니다. 새 공통 빌드의 실제 Electron 전체27검사가 통과했습니다. 질문 인용 v2의 고정 참조, 의미 보고의 유효 부분 보존, OCR 회전·배치 경고는 기존 UI 응답 계약으로 연결하며 새 UI 스키마를 만들지 않았습니다.

## 완료 조건과 근거

- **충족**: 업무별 main/IPC/preload/platform/라우터를 연결하고 문서→질문→저장 답변→결과 초안→Wiki 문서 복귀, DOCX→변환→원본만 질문, 원본→계획→기존 작업 확인과 부분 작업 명시 재개를 격리 서버·Electron에서 확인합니다.
- **충족**: 기존 저장/복원·권한 회수·CAS·응답 유실·부분 결과와 신규 저장 경로를 구별하고 실행 재개가 새 작업이나 저장된 Wiki의 추가 이력을 만들지 않음을 확인합니다.
- **충족**: 1920 기존 치수, 1280 패널/입력/포커스, 3440 읽기 폭·지도 배율을 실제 내부 창 크기로 확인합니다. 모든 입력 조합·물리 모니터·OS 배율 인증으로 확대하지 않습니다.
- **로컬 통합 충족 / 실제 질문 결과의 후속 통합 충족**: TypeScript4종·전체 Oxc·형식·토큰148개·도구27검사·제품 빌드와 수정 후 Electron 전체27검사를 통과했습니다. 실제 서버·macOS 보호 저장을 사용했으며 모델 출력은 합성입니다. 현재 [실행 로그](../../../app/release/quality-fixes-20261026/verification/e2e.log)와 최초 실패·실제 모델 미완료 구간은 [HISTORY](HISTORY.md)에 구분해 기록합니다.
- **충족**: feature ui/model/api·공개 index, 한국어 주석·명시적 타입·RHF/Zod·SCSS·any/deprecated 금지를 유지합니다.

## 남은 통합과 실제 환경

- 명시 승인한 실제 CLI 질문 결과의 답변/인용5개를 수정 없이 기존 실행에 제출해 저장 영수증을 확인했습니다. 실제 Electron에서 결과 보관→초안 편집→명시 Wiki 반영→이전 전체 본문 이력 확인→완전 종료/재시작→같은 Wiki revision 재조회를 통과했습니다. [API 근거](../../../app/release/quality-fixes-20261026/verification/question-flow-v010-20261026/api-summary.json)와 [UI 근거](../../../app/release/quality-fixes-20261026/verification/question-flow-v010-20261026/ui-summary.json)를 따릅니다. UI에서 모델을 다시 호출한 전체 흐름 시험이나 답변 의미 승인으로 확대하지 않습니다.
- 기존 RFC9111의 질문/의미 검사 실패 [증거](../../../app/release/verification/live-final-summary.json)는 보존합니다. 새 RFC9110 평가4회에서는 질문 후속 통합이 성공했지만 추출 의미 오류와 검사 위치 오류가 드러났고 지침을 보완했습니다. 의미 평가의 원시 결과와 새 원문 최종 검증은 [ontology 계획](../ontology/PLAN.md)을 따릅니다.
- 실제 Windows 앱 설치·보호 저장·실행/취소, 두 PC·운영 HTTPS 서버는 미검증입니다. Windows 개인 실행은 현재 PC의 보호 파일·프로세스 트리 종료 probe가 runtime_ready를 확인해야 허용합니다. 고정 not_certified 표시를 실행 가능 조건으로 사용하지 않으며, 제품의 Windows 릴리스 인증 상태 자체는 여전히 미완료입니다. NSIS 교차 빌드 성공으로 실기기 검증을 대신하지 않습니다.
- 배포 서명·공증에는 기존 Developer ID와 공증 키체인 profile이 필요합니다. 새 계정/구매/공개 배포를 만들지 않았습니다.
- 실제 문서 의미 정확도의 기존 독립 [공개 평가](../../../evals/rfc9111_stale_20261026/REPORT.md)는 보존합니다. 규범 텍스트 보존 지침의 실제 모델 개선은 미확인입니다. OCR 회전·한글 배치의 일부 표본은 개선됐지만 공개 문서 일부 구간의 오류 증가와 다단 읽기 순서 한계가 남아 있으며 [sources 검증 기록](../sources/HISTORY.md)을 따릅니다.

요청받지 않은 후속은 자동 진행하지 않습니다.
