# Wiki 문서·저장 계획

## 현재 상태

파일 저장·읽기·전체 버저닝·CAS·잠금/크기/실패 보존 구현 완료. 일반 API의 문서 목록·전체 본문 읽기도 구현 완료.

HTTP 본문 저장·과거 버전 목록/전체 본문·복원도 기존 WikiStore와 안전한 이력 조회로 연결했습니다. 저장 직전 권한을 재확인하고 과거 전체 본문/작성 정보 미기록을 보존합니다. 계약과 실제 검사 결과는 [API 계획](../platform/PLAN.md)·[API 작업 기록](../platform/HISTORY.md#2026-10-25--잔여-http-api-전체-연결)에 둡니다.

개인 저장 결과의 편집 초안·원래 생성문·전체 고정 근거·답변 계보를 보존하고 Wiki에 명시 반영하는 API를 추가했습니다. 초안/대상 본문의 CAS와 최신 근거 관측값을 함께 요구하며 변경 근거의 명시 확인·저장 영수증을 제공합니다. 전체 근거 부록까지 1MiB 제한을 적용하고 임의 축약하지 않습니다. 해당 검증은 [API 작업 기록](../platform/HISTORY.md#2026-10-25--시안-기준-부족한-api-구현)에 둡니다.

문서 목록과 본문 query에 허용된 profile 선택을 추가해 UI의 선택 관점과 실제 응답/cursor 기준을 일치시켰습니다. 관점 권한 거부·다른 관점 cursor 재사용 거부·빈/공백/1MiB 본문의 원문 보존을 포함한 읽기 API14검사가 통과했습니다. 화면 통합의 현재 범위/검증은 [ui PLAN](../ui/PLAN.md)이 관리합니다.

## 다음 요청에서 확인할 범위

문서 편집·이력/복원 API를 사용하는 제품 화면 연결은 후속입니다.

## 완료 조건

변경한 저장 경로의 정상·충돌·실패 보존을 격리 데이터로 검증합니다. 기존 원문·모든 과거 파일과 revision 계약을 유지합니다.
