# 검토·전문가 판단 계획

## 현재 상태

원문 근거 검토·수정·되돌림과 별도 권한의 전문가 정책·Action log·현재 판단 조회 구현 완료. 검토/정책 원장과 과거 판단을 보존합니다.

문서별 검토/정책·각 되돌림·전체 원장 검증 후 이벤트 페이지/단건 HTTP API를 연결했습니다. 선택 callback으로 최종 쓰기 직전 권한을 재확인하며 기존 MCP 동작을 유지합니다. 명시 범위 검토함/이력 집계와 실제 검증은 [API 계획](../platform/PLAN.md)·[API 작업 기록](../platform/HISTORY.md#2026-10-25--잔여-http-api-전체-연결)을 따릅니다.

현재 허용 공간 전체 검토함/이력 조회와 저장 전 추출안의 미발견 관계 판단을 추가했습니다. 제외는 이번 비교의 판단이며 원문 사실의 삭제/부정이 아닙니다. 복구/재추출도 전체 추출안·새 세대 적용·실제 claim 검토를 거치며 옛 승인을 이식하지 않습니다. [API 계약](../platform/DECISIONS.md#d-051--시안의-분석비교결과질문집계를-지원하는-api-2026-10-25)과 [검증 기록](../platform/HISTORY.md#2026-10-25--시안-기준-부족한-api-구현)을 따릅니다.

## 다음 요청에서 확인할 범위

제품 검토 화면·실제 전문가 과제·원장 운영 확장은 남아 있습니다. 공간 전체 집계도 한도/누락 상태를 확인하며 전역 단일 거래 시점으로 해석하지 않습니다.

## 완료 조건

claim_id/state_revision·전체 한정어/관점/출처를 유지하고 경쟁·실패·되돌림·재추출 후 재검토를 검증합니다. 기계층과 effective_graph/policies를 구분합니다.
