# 개념 조회·연결·영향 계획

## 현재 상태

문서 간 명시 링크/공통 개념 후보, 선택 원문·전체 그래프 맥락, 직접 변경 영향과 개념 중심 통합 조회 구현 완료.

위 조회의 HTTP API와 문서 검색/기계 그래프 조회·명시 범위 집계·질문 근거 준비를 기존 서비스로 연결했습니다. 질문 준비는 원본만 선택할 수도 있고 전체 원문·유효 지식·정책·선택 주장/불변 원본과 누락 상태를 보존합니다. 실제 결과는 [API 작업 기록](../platform/HISTORY.md#2026-10-25--잔여-http-api-전체-연결)에 둡니다.

검토함·이력은 `coverage=tenant`로 현재 허용 공간의 문서/대응과 본인 분석 작업을 발견할 수 있습니다. 종류별1,000개·입력8MiB·출력2,000항목 한도와 누락/불완전 상태를 공개하며 페이지는 주체·관점·발견 목록·자료 판본에 묶입니다. 질문에는 고정 입력의 실행 인계/사용권·진행·취소·답변 제출 API를 추가했고 문서 인용·기계 주장·전문가 Action log를 구분합니다. 실제 AI 실행과 의미 검증은 하지 않습니다. 상세 계약·핵심 검증은 [API 계획](../platform/PLAN.md)·[작업 기록](../platform/HISTORY.md#2026-10-25--시안-기준-부족한-api-구현)에 둡니다.
