## 2026-11-25 — 문서 목록·검색의 선택적 원본 계보 묶기

- `GET /documents`·`GET /documents/search`에서 `group_sources=true`를 요청할 때만 현재 원본 판본의 실제 `metadata.source.id/version`을 기준으로 결과를 묶는다. 다수 Wiki의 경로·현재 revision·metadata·authorship를 원본 행 `documents`에 모두 보존하며 이전 원본 판본·미등록 계보·동명 독립 문서는 숨기지 않는다. 원본 카탈로그와 Wiki/히스토리를 수정하지 않는다.
- 목록은 계보별 행을 만든 뒤 페이지화하고 cursor에 묶기 설정·현재 자료·권한 범위를 반영한다. 계보만 기존 재생성 가능한 SQLite 색인에 캐시하며 읽기 실패는 캐시하지 않는다. 검색은 기존 원문 탐색 한도와 truncated/skipped를 유지하고 묶기용 추가 읽기가 실패해도 기존 일치 문서 경로를 반환한다. 기본 조회·MCP 계약은 유지한다.
- 격리 `test_catalogue_lineage` 9개와 기존 `test_document_read_index`·`test_storage`·`test_document_management`를 합친 53검사 통과. 여러 결과/이전 판본/동명 자료, 페이지·scope·catalog 변경, warm read·색인 장애, 읽기 실패 후 복구, 검색 부분 상태, HTTP 기본 호환·권한, 원문·히스토리 무변경을 확인했다. 실제 데이터 변경·배포는 수행하지 않았다.
