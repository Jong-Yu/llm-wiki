## 2026-11-22 — 남은 조회 변경의 커밋 검토와 줄 좌표 보완

- MCP `wiki_read(view="lines")`가 `splitlines()`로 FF·Unicode 구분자를 줄바꿈으로 세어 `knowledge_lookup`의 CRLF/CR/LF 좌표와 달라지는 오류를 재현했다. 같은 좌표로 읽도록 맞추고 실제 후보 구절→줄 조회에서 본문·전체 줄 수·판본이 일치하는 회귀를 추가했다.
- tenant 도구 설명의 '저장 후에만 영향 조회' 축약이 변경 전 기준 캡처를 막아 기존 4판본 캡처 안내를 복원했다. 저장 완료 후 오류 때문에 저장을 재시도하지 않는 규칙을 유지한다.
- D-130의 안내 한 문장이 추가된 뒤 남아 있던 프롬프트 SHA 3개 기대값을 갱신했다. 그 문장만 제거하면 이전 SHA와 정확히 같음을 확인했으며 실제 지침을 검사에 맞춰 되돌리지 않았다. 관련8검사와 전체 Python 회귀가 통과했다. 실제 모델 재평가·사용자 문서 변경은 수행하지 않았다.

## 2026-11-22 — 질문 조회 속도 개선(결과 동일)
