# API·MCP·실행 환경 계획

## 현재 상태

Codex·Claude Code 선택을 공통 개인 실행기에 연결했습니다. 분석·질문·추출안·별도 의미 검사에서 같은 제공자를 사용하며 기존 Codex 기본값과 저장/취소/복구 흐름을 유지합니다. Claude의 구조화 출력·환경 제한·OS 입력 한도·로그인 진단과 두 제공자의 격리 CLI 통합을 검증했습니다. 실제 Claude 모델 호출은 로그인 완료 후 확인할 범위이며 Windows 실기기 검증으로 확대하지 않습니다. 계약은 [D-065](../analysis/DECISIONS.md#d-065--codexclaude-실행-기록과-고정-규약-호환-2026-10-26), 실제 결과는 [HISTORY](HISTORY.md)를 따릅니다.

질문 인용의 공개 실패를 재현하고 `personal-question-v2`를 구현했습니다. 새 실행은 고정 근거의 문서·등록 원본·기계 주장·활성 정책 참조를 공개하며 개인 실행기는 실제 식별자 조합만 출력 스키마에 허용합니다. 기존 v1 계약·서버의 엄격한 검증·권한/CAS·응답 유실 보존은 유지합니다. 모델 완료와 heartbeat 응답이 겹칠 때의 사용권 충돌도 재현·수정했습니다. 이번 질문·OCR·의미 검사·추출 지침 수정의 공통 Python 회귀 **999개가 통과**하여 구현 통합을 완료했습니다. 명시 승인한 실제 질문 모델의 원시 답변/인용5개를 기존 고정 입력에 그대로 제출해 저장 영수증을 확인했고 Electron 결과·초안·Wiki 반영·재시작 재조회를 통과했습니다. 추출 의미 정확도는 별도 ontology 평가와 구분합니다. 계약은 [D-060](DECISIONS.md#d-060--고정-근거에서-선택하는-질문-인용-계약-2026-10-26), 실제 결과는 [HISTORY](HISTORY.md)를 따릅니다.

데스크톱 공통 실행 브리지·생성 중 취소 회수·WSL2/Linux 배포 묶음과 읽기 전용 사전 점검을 구현했습니다. 앱에는 토큰 stdin/개인 파일/프로세스 트리 계약을 제공합니다. Windows의 고정 인증 문자열 차단은 현재 PC의 실제 보호 파일·프로세스 트리 진단으로 대체했고, 실패 시 실행을 거부합니다. 실제 Windows 앱 배포 검증은 미완료로 유지합니다. 계약은 [D-064](DECISIONS.md#d-064--windows-실행-전-실제-보호-기능-진단-2026-10-26)을 따릅니다. 서버 도구는 명시 TLS/Caddy/systemd/Windows 시작 스크립트와 보존·되돌림 절차를 새 폴더로만 생성합니다. 사용자가 Windows/WSL2 환경을 설치 중이며 실제 설치·HTTPS·재부팅·다른 PC 연결 검증은 아직 수행하지 않았습니다. 백업·복원 시험은 사용자의 v0.1.0 범위에서 제외했으며 기존 보존 도구·기록을 삭제하지 않습니다. 서버 계약은 [D-059](DECISIONS.md#d-059--데스크톱-실행-브리지와-명시-서버-배포-준비-2026-10-25), 실행은 [README](../../../README.md#서버-배포-묶음과-사전-점검)를 따릅니다.

macOS 실제 Tesseract 5.5.3/kor+eng 준비와 원문·fixture OCR/취소/영수증 검증을 완료했고 doctor에서 언어 준비를 통합했습니다. OCR의 의미 정확도·원문 전체 포함·임의 회전 보정은 완료로 표시하지 않습니다. 이전 통합의 전체970개 회귀와 이번 개선의 검증/한계는 [HISTORY](HISTORY.md)에 구분해 기록합니다.

개인 실행 환경 설치·보호 토큰 생성·읽기 전용 진단과 Windows 네이티브 실행 경계를 구현했습니다. Python 의존성을 잠그고 질문 실행·문서 변환·별도 의미 검사 모듈을 공통 실행기에 연결했습니다. 분석 실행 전 작업 CAS와 동일 기준의 실제 영수증을 확인하는 부분 재개를 구현하여 이미 저장한 위키를 재저장하지 않습니다. 설치/실행법은 [README](../../../README.md#실행-방법), 계약은 [D-055](DECISIONS.md#d-055--개인-실행-환경과-읽기-전용-진단안전한-재개-2026-10-25), PC 보호 연결은 [D-057](DECISIONS.md#d-057--pc-연결-보호-저장과-재시작-재확인-2026-10-25)을 따릅니다.

Python 통합 회귀에서 발견한 바이너리 산출물 다운로드의 MIME 기본값과 오래된 MCP 도구 목록 기대값을 수정하고 영향 범위 재검사를 완료했습니다. 이번 Python 구현·통합 범위를 완료했으며 실제 검증과 미실행 OS 등의 한계는 [HISTORY](HISTORY.md#2026-10-25--개인-pc-실행-환경과-python-병렬-통합)에 기록합니다.

후속 코드 점검에서 발견한 서버 오류4개(연속 복구 검토 누락·계획 자기 저장 승계·최초 상태 연결 실패·입력 읽기 예산)를 수정했습니다. API 입력과 화면은 유지하며 실제 핵심 검증은 [analysis HISTORY](../analysis/HISTORY.md#2026-10-25--서버-오류4개-수정)가 관리합니다.

시안 대조에서 부족했던 서버 API 구현을 완료했습니다. 기존62개에 변환 보고·분석 계획/인계7개, 저장 전 추출안/미발견 관계8개, 결과 초안/반영6개, 개인 질문 실행10개를 추가해 총93개 동작/84개 경로를 제공합니다. 기존 검토함·이력에는 허용 공간 전체 집계를 추가했습니다. 기존 업무 모듈과 공통 JSON·인가·불변 공개·개인 기록·전체 이력·CAS를 재사용하며 화면 파일은 이 작업에서 편집하지 않았습니다. 계약은 [D-051](DECISIONS.md#d-051--시안의-분석비교결과질문집계를-지원하는-api-2026-10-25), 실제 핵심 검증과 한계는 [HISTORY](HISTORY.md#2026-10-25--시안-기준-부족한-api-구현)에 둡니다.

업무별 core/modules·api/mcp 어댑터·runtime·tools·core/tests 구조 이전 완료. 단일 ASGI 앱의 첫 읽기·원본 등록 API와 MCP 결합도 구현 완료. 작업 접수 API/MCP·개발 CLI 원본 인계의 현재 범위/검증은 [analysis](../analysis/PLAN.md)가 소유합니다.

기존 API·분석 입력 코드의 수신 제한·취소 대기·CLI 전송을 공통 모듈로 정리하고 저장/권한/버전 처리의 한국어 주석을 보완했습니다. 실제 검증은 [HISTORY](HISTORY.md)에 기록합니다.

백엔드·CLI 생산용 Python 전체를 점검해 입문자용 설명이 부족한 파일의 주석 보강을 완료했습니다. 코드·기존 문자열·배포 검증 지문은 유지하며 기능 상태를 변경한 작업은 아닙니다.

## 다음 요청에서 확인할 범위

Windows 초보 설치 안내는 [단일 PDF](../../../output/pdf/WSL2_SERVER_GUIDE.pdf)·[브라우저 보기](../../WSL2_SERVER_GUIDE.html)·[원문](../../WSL2_SERVER_GUIDE.md)에서 관리합니다. 집 밖에서도 접속하려는 사용자 요청에 맞춰 Cloudflare 고정 Tunnel, 개인 인증, Windows 작업 스케줄러와 현장 완료 기준을 단계별로 설명하며 기존 자료 보존 이전을 분리합니다. 문서/격리 검증과 Windows 실기기 설치·외부 HTTPS·재부팅 완료를 구분합니다. 실제 결과는 [이번 안내 보강 기록](HISTORY.md#2026-10-26--초보자용-외부-접속-서버-가이드-보강)을 따릅니다.

Electron 화면의 최종 통합은 UI 도메인이 관리합니다. 개인 질문 실행기·PDF/Excel/DOCX/이미지 변환기와 설치/진단은 구현했으며 사용자 문서 OCR 정확도·임의 회전/복잡한 배치·사용자 문서 의미 정확도·Windows 네이티브 실기기·WSL2 설치/재부팅·HTTPS/자동 시작·다른 PC의 실제 연결은 별도 검증이 남습니다. 서버는 AI나 변환기를 실행하지 않습니다. 운영 권한 부여·자료 이전은 자동 수행하지 않습니다. 대화/답변/비교/초안/실행은 개인 보관이며 공유·삭제/보관 만료·자동 의미 비교는 이번 완료 범위가 아닙니다.
