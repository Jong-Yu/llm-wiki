# Wiki 변경 절차 선택

기존 `$wiki-maintain` 호출을 유지하는 진입점이다. 요청에 필요한 아래 스킬만 읽고 그 절차로 실행한다. 별도 저장·검토 계약을 여기에 복제하지 않는다.

| 요청 | 사용할 절차 |
| --- | --- |
| 본문 작성·정정, 과거 내용 비교·판본 복원 | [wiki-edit](../wiki-edit/SKILL.md) |
| 원문 검토·전문가 판단·독립 관계·문서 대응·Clean Up·되돌림 | [wiki-review](../wiki-review/SKILL.md) |
| 등록 원본 분석·온톨로지 추출 | 함께 요청된 경우 [wiki-analyze](../wiki-analyze/SKILL.md) |
| 변경 없이 현재 지식·검토 대상 조회 | [wiki-query](../wiki-query/SKILL.md) |

여러 종류의 변경은 사용자의 대상·범위와 실제 의존 순서에 맞춰 진행한다. 본문 변경으로 그래프·판단 기준이 달라지면 다음 작업의 최신 근거를 다시 읽는다. 이전 revision·승인을 새 변경에 복사하지 않는다. 각 저장의 성공·경고·미실행을 따로 보존하며 후속 실패가 앞선 저장을 자동 재시도하게 만들지 않는다. 명확한 요청의 승인을 반복하지 않고, 단순 “검토” 요청을 사람이 결정한 승인으로 해석하지 않는다.
