# 서버 (재)시작과 주소 확인

사용자가 서버를 재시작·시작하거나 새 코드를 서버에 반영하라고 요청할 때만 사용합니다. 데이터(`data/`, `.local/tenancy/`)는 읽거나 쓰지 않고 런처만 다룹니다.

## 시작·재시작

1. 프로젝트 루트에서 실행합니다(포트 생략 시 8766).
   ```bash
   tools/open-server-terminal-mac.sh [포트]
   ```
2. 스크립트가 하는 일: 이 프로젝트의 `tools/start-mac.command` 런처만 정상 종료(TERM)하고(서버·터널이 함께 내려감), 포트가 비면 macOS 터미널 창을 열어 런처를 실행합니다. 터미널 창이라 Claude 세션이 끝나도 서버가 유지됩니다.
3. 끝나면 새 터널 주소가 출력됩니다. 주소는 `.local/last-server-url.txt`에도 있습니다(`.local/`은 git 제외, 인증 정보 없음).

## 지킬 것

- 재시작하면 터널 주소가 바뀝니다. 사용자의 클라이언트·MCP 설정을 새 주소로 바꿔야 한다고 알립니다.
- 다른 프로세스가 포트를 쓰고 있으면 스크립트가 중단합니다. 그 프로세스를 임의로 종료하지 않고 사용자에게 알립니다.
- 터널 공개는 사용자가 요청한 때만 시작합니다. 서버 로그·토큰·인증 정보를 출력하거나 기록하지 않습니다.
- 처음 실행하면 macOS가 "터미널 제어 허용"을 물을 수 있습니다. 허용되지 않으면 사용자가 `tools/start-mac.command`를 직접 실행해야 합니다.

## 상태만 확인

```bash
lsof -nP -iTCP:8766 -sTCP:LISTEN   # 포트 사용 여부
cat .local/last-server-url.txt     # 현재 터널 주소(서버가 떠 있을 때만 존재)
```
